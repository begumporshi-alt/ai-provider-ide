## Non-negotiables
- A tool result is not evidence. **A `Write`/`Edit` can report success while the file keeps its old bytes *and* mtime** — `Read` serves the *unwritten* text. Verify by `stat` mtime + **Grep tool**, retrying until it moves. **An inserting `Edit` must not shrink its anchor block** — a heading inside the anchor is *deleted* if the replacement omits it (D53; `### Housekeeping` again today).
- Falsify **one** probe at a time; measure before recording a cause — **a reason is a claim too** ("cannot be tested" needs the evidence "is not tested" does). **A fix's sweep covers where the claim *appears*, not where the fix *touched*** (D44/D52). **A green suite is not proof it exercises the new transport** — probe the path, and **check the probe's condition against the fixture**: a falsification that cannot fire looks exactly like a fix that works. **Re-snapshot after every accepted change; `touch` sources after a probe run** — a stale snapshot deletes the fix, a preserved mtime leaves the build stale. **A plan's future tense is a claim** — grep the impl, excluding `#[cfg(test)]` hits (D39/D40). **Calibrate the instrument, not just the reading.**
- Unset **all six** proxy vars on probe *and* app — else `502`. **A proxy `502` satisfies a "status != 000" readiness loop**.
- `./node_modules/.bin/tsc`, never `npx tsc`. Gate needs `PATH="$HOME/.cargo/bin:$PATH"`. **Shell is bash 3.2 here** — no `mapfile`. Commit msgs via `-F <file>`.
- **One edit per file per batch** — the 2nd lands on a stale snapshot and clobbers the 1st; both report success.
- Absence claims: **Grep tool** (bash `grep` lies — **`\|` alternation returns false zeros**) — **skips dot-dirs** (`.github/`, `.workbuddy-ai/` → `cat <dir>/* | grep`). **An instrument can be *empty*, not merely mispatterned** — `launchctl print`, never `launchctl list`. **Calibrate against a known-present control**; count via node.
- **Shell traps**: zsh does **not** expand `$'\t'` inside `${x// /…}` — split with `read` and let `printf` own the tabs. **Defects stack; the loud one hides the quiet ones** — "it fails loudly" is a reason to look next, not away.
- **A harness for the wrong transport is not a harness**; **one that answers unconditionally can't see a listener dependency**; **one that fabricates a shape is worse than one that throws** → `REFERENCE.md`.
## Where things are
- **Two live request paths, two router implementations.** `aiproviderd` (Rust) serves gateway clients on `127.0.0.1:8800`; the **webview** separately runs the TS `packages/router-core` router (`store.ts:138` → `Assistant.tsx`). A routing rule change needs **both**; find it by its *call site*, not the class name.
- `ARCHITECTURE.md` is a spec, not the app. `dev-book/` = rules/contracts + drift register; `check-doc-links` is a gate.
- Playground = **Assistant**; skills are frontend-only (gateway blind). **DB path, ports, corpus sizes, sandbox files → `REFERENCE.md`.**
- Identity = **two** strings, either may deny: `AIP-Agent`, `key:<id>`. Use `core.app_keys()`, never `AppKeyProvider`. **A `gateway_keys` row whose `gwkey:` vault secret is missing authenticates nothing** — the token is compared to the *secret*, not the row id.
- **Clippy and rustfmt are gates**; triage clippy by lint *kind* — count ≠ signal. **Snapshot before `--fix`**: it *moves* code. **A `-D warnings` gate on floating `stable` goes red with no code change** — `rustup update stable` first.
- The service binary ships **undeclared** (the bundler copies the `[[bin]]` target); `tauri build` builds the **default-features** one, which **links WebKit**.

## Recall & scope
- **Paths differ on one axis: scope**; atoms are born unscoped and `assign_scope` is the only way in — drain must NOT auto-bind. Derive identity from identity, never from place. A per-principal master-switch row beats the client's `AIP-Memory` header; `superseded_at` (0014) hides rows from recall/session/injectable, **not** `list`.

## Rules that cost a bug

**Auth / install** — Secrets are **file-backed** (`<data_dir>/.secrets.json`, mode 600), **not the OS keychain** (27a removed `keyring`): a stale keychain item is readable but **no longer read**. **503 = the read did not complete** (a local fault, not a rejected credential); a *missing* `masterkey` is **401**; **401** = the check ran, so the gateway is healthy. **`bootstrap` registers a job; it never execs it** — prove by **pid + marker**, never `state`. → `REFERENCE.md`.

**The listener** — **The gateway is a listener the app *starts*, not a precondition**: 3 states, since "never chosen" ≠ "turned off". **A listener with no master key 401s *everything*** → mint the first key on `Absent`, never `Unavailable`. **`TypeError` = unreachable; any other `Error` = a real fault** — degrade on the first only. Nothing is an image model unless a manifest says so. **Three 429 shapes — read the body**; `Retry-After` = shortest wait. **A 429 cools its key 1 s**; all cooled ⇒ `NO_ROUTE` instantly. **The auth breaker is half-open (60 s), not a latch** — exclusion is never permanent evidence. **`AUTH_FAILED` is retryable with the next key** — a chain containing it is *not* a failed request; read `status`. **A `401` can be about the *client*, not the key** — a gateway allowlisting client families refuses *before* reading the credential; classify it `unverified`, never `invalid` (conclusive ⇒ pulls a working key). → `REFERENCE.md`.

**Tauri boundary** — a `#[tauri::command]` arg, a serde field and the Rust→webview `BridgeRequest` are **different boundaries**; only nested payloads hit serde → `deny_unknown_fields` on each. A tool failure must never reach the model as `""` — guard at bridge *and* consumer. → `REFERENCE.md`.

**Data & migrations** — **`Store::migrate` skips by VERSION, not name, and numbers `MIGRATIONS` + `DATA_MIGRATIONS` as one sequence** — append a new *schema* step to **`DATA_MIGRATIONS`**, never insert into `MIGRATIONS`: inserting shifts data migrations up one, so an existing DB re-runs the last and never applies the new step (cost a pass). **Adding a column proves nothing about the writer** — trace router → `store.ts` → INSERT. **A two-store write needs a rollback on the *second* store's failure** — and **count a stated invariant's enforcement sites**: 3 of 4 held this one, and the miss held the credential. **`ledger.key_id` is the *provider* credential (`api_keys.id`), not the gateway app key.** **`NULL` ≠ `0`** — "no cap" is `NULL`. `panic = "abort"`; a debounced save reads state when it **fires**. **`settings_set` is a whole-row UPSERT** — known keys only erases the rest; the HTTP routes **merge**. **Never pre-parse a number** (`Number("")` = `0` = *unlimited*). **A cache needs an authority, not just a TTL.** → `REFERENCE.md`.

**Tests & specs** — **vitest does not typecheck**: `expect(x,"msg").toBe(true)`, not `toBe(true,"msg")`; run the gate. **A test can pass while the request path diverges** — two fixes for one property mask each other (select by content, not index); a mechanism test passes while the path passes a private copy; **a test that sets a field directly proves the *consumer*, not the *producer***. Pin the property end-to-end. → `REFERENCE.md`.

**UI** — Overlapping reads need a **generation counter** (StrictMode double-fires mounts), and **StrictMode double-mounts `bootstrap()` too** — share one in-flight promise, set ready only at the *end*: a guard that is *correct* and one that has *run* differ. **A switch in two places drifts** — Control owns cross-cutting ones; move, don't mirror. **A swallowed write is invisible to every reader** — one `writeTrail` helper. **The repo is PUBLIC** — `pnpm key-leak-grep` is a gate step; fixtures synthetic. `getByText`/readiness-wait, accessible-name, per-trail channels → `REFERENCE.md`.
