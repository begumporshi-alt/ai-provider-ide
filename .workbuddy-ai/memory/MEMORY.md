## Non-negotiables
- A tool result is not evidence. **A `Write`/`Edit` can report success while the file keeps its old bytes *and* mtime** — `Read` serves the *unwritten* text. Verify by `stat` mtime + **Grep tool**, retrying until it moves. **An inserting `Edit` must not shrink its anchor block** — and an existing row used as the anchor for a new one is *deleted*, not preceded (D53 clobbered this way).
- Falsify **one** probe at a time; measure before recording a cause — **a reason is a claim too** ("cannot be tested" needs the evidence "is not tested" does). **A fix's sweep covers where the claim *appears*, not where the fix *touched*** (D44/D52). **A green suite is not proof it exercises the new transport** — probe the path. **Re-snapshot after every accepted change; `touch` sources after a probe run** — a stale snapshot deletes the fix, a preserved mtime leaves the build stale. **A plan's future tense is a claim**: "`x` will implement it" needs an `impl <Trait> for` grep whose hits aren't all `#[cfg(test)]` (D39/D40). **Calibrate the instrument, not just the reading.** **A hedge does not survive being quoted** — §2.1.3's *"has not been run"* became three flat assertions (D54).
- Unset **all six** proxy vars on probe *and* app — else `502`. **A proxy `502` satisfies a "status != 000" readiness loop**.
- `./node_modules/.bin/tsc`, never `npx tsc`. Gate needs `PATH="$HOME/.cargo/bin:$PATH"`. **Shell is bash 3.2 here** — no `mapfile`. Commit msgs via `-F <file>`.
- **One edit per file per batch** — the 2nd lands on a stale snapshot and clobbers the 1st; both report success.
- Absence claims: **Grep tool** (bash `grep` lies — **`\|` alternation returns false zeros**, a BRE pattern matching *nothing*, so **prove the instrument reports presence**) — **skips dot-dirs** (`.github/`, `.workbuddy-ai/` → `cat <dir>/* | grep`). A hit ≠ completeness; count via node.
- **A harness for the wrong transport is not a harness**; **one that answers unconditionally can't see a listener dependency**; **one that fabricates a shape is worse than one that throws** — `{ok:true}` where the route answers `{version}` reads as `undefined`, not an error. Cargo feature unification, the Playwright guard → `REFERENCE.md`.

## Rules that cost a bug

**Auth / install** — **Reinstalling costs one keychain approval**; until granted *every* request answers `503 master key unavailable` (precedes auth); **401** = healthy. **Never pin a signing identity in `tauri.conf.json`** — CI cannot catch it; build to verify. **`memory_enabled` is in-memory only**, `Disabled` outranks `WriteOnly`; check the Memory screen, not HTTP. **`bootstrap` registers a job; it never execs it** — a `0644` binary gives a job launchd reports *loaded* whose spawns `EACCES` until `KeepAlive` throttles it. Prove a job by **pid + its marker**.

**The listener** — **The gateway is a listener the app *starts*, not a precondition**: 3 states, since "never chosen" ≠ "turned off". **A listener with no master key 401s *everything*** → mint the first key on `Absent`, never `Unavailable`. **`TypeError` = unreachable; any other `Error` = a real fault** — degrade on the first only, so a corrupt DB still reads as one. Nothing is an image model unless a manifest says so. §3.5 = **two semaphores**: `permits` *admits*, `dispatch` *routes*. **Three different 429s — read the body**; probe headers are **lowercase**; client-facing `Retry-After` = the **shortest** wait. A DB-unique id needs a boot marker. **Caps are independent, not narrowed** — an app cap under a global still breaches it; two 402 codes.

**Tauri boundary** — A `#[tauri::command]` arg, a serde field and the Rust→webview `BridgeRequest` are **different boundaries**; **a field on one side is not wiring**; only nested payloads hit serde → give every nested payload `deny_unknown_fields`. `shim.ts:toRustArgs` snake_cases top-level keys; **every new command needs a `web-test/shim.ts` case the same day**. A tool failure must never reach the model as `""` — guard at bridge *and* consumer.

**Data & migrations** — Migration = SQL/`DATA_MIGRATIONS` + bump `schema_version` + count assertion + table list. **Adding a column proves nothing about the writer** — trace TS router → `store.ts` → command → INSERT. **`ledger.key_id` is the *provider* credential (`api_keys.id`), not the gateway app key.** **`NULL` ≠ `0`** — "no cap" is `NULL`; two spellings of one state is the defect. `panic = "abort"` — no poison handling; a debounced save reads state when it **fires**. **`settings_set` is a whole-row UPSERT** (`commands.rs:197`) — known keys only erases the rest; the HTTP settings routes **merge**. Clamp from numbers/numeric strings only; **never pre-parse** (`Number("")` = `0` = *unlimited*). **A cache needs an authority, not just a TTL.**

**Tests & specs** — **vitest does not typecheck**: `expect(x,"msg").toBe(true)`, not `toBe(true,"msg")`; run the gate. `serde_json` sorts keys — parse, never substring. **Two fixes for one property mask each other** — select by content, not index. `__webTest.failNext`: an immediate failure can't test supersession; a negative assertion on an auto-dismissing surface **can never fail**. **A spec must not prove a round-trip by an input's value** — assert on the row re-read from the host. **A drift guard is not a behaviour guard**; **a cap is enforced where its function is *called*, not described**; **a mechanism test passes while the request path passes a private copy** — pin the property end-to-end. **A `&mut` parameter on shared state is a concurrency ceiling** — share via `Arc`+interior mutability. **A fixture's comment is a claim about the invariant the test needs** — a wrong one hides the defect *from inside* the suite meant to catch it.

**UI** — Overlapping reads need a **generation counter** (StrictMode double-fires mounts), and **StrictMode double-mounts `bootstrap()` too** — share one in-flight promise, set ready only at the *end*: a guard that is *correct* and one that has *run* differ. **A switch in two places drifts** — Control owns cross-cutting ones; move, don't mirror; accessible name must not change with state. `getByText` matching two = a **duplicated fact on screen**; a readiness wait must match only the awaited view. **A swallowed write is invisible to every reader** — one `writeTrail` helper, one channel **per trail**. **The repo is PUBLIC** — `pnpm key-leak-grep` is a gate step; fixtures synthetic.
