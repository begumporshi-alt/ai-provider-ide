## §6.3 — agnes cache probe (RESOLVED)
Probed the live gateway (127.0.0.1:8800, master key) with three requests:
1. Short prompt + Anthropic-style `cache_control` on system block → usage: only `prompt_tokens`,
   `completion_tokens`; no cache fields.
2. 5,215-token prompt, call 1 (cold) → no cache fields.
3. 5,215-token prompt, call 2 (warm) → no cache fields; `prompt_tokens` unchanged at 5,215.

**Conclusion: agnes does not report any prefix-cache fields.** `raw_keys: ["completion_tokens",
"prompt_tokens"]` in every response. Option 2 (prompt caching) has zero billing effect on the
currently configured provider. The comparison to OmniRoute's compression claim is unresolved until
a provider with prefix caching is added.
